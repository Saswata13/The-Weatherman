# The-Weatherman
A simple live weather application for cities all around the world, built with HTML, CSS and JavaScript on the
[Weatherbit](https://www.weatherbit.io/) current-weather API.

## Run it
1. Get a free API key at https://www.weatherbit.io/account/create.
2. Copy `config.example.js` to `config.js` and put your key in it. `config.js` is git-ignored, so the key stays
   on your computer.
3. Open `index.html` in a browser and search for a city.

Note: a key in front-end code is visible to anyone who loads the page, so use a free-tier key and do not publish
`config.js` with the site.
